
# Project Overview

This project focuses on designing a compact and practical charger PCB while exploring electronic circuit design, PCB layout, and hardware development using KiCad.

## How to open the project

To explore or modify this project:

1. Download or clone this repository.
2. Install [KiCad](https://www.kicad.org/).
3. Open the `.kicad_pro` project file.
4. Explore the schematic and PCB layout.
5. Make modifications or improve the design.
